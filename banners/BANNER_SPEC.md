# 主站头图轮播：四张 banner 图片要求

主站 `nagisheart.fun` 第一屏是一个左右滑动的轮播，共两张：第 1 张 NagiChat，第 2 张 Nagi's Heart。每张有 PC、手机两个版本，一共四张图。

## 一、文件清单

| 文件名 | 用途 | 尺寸（像素） | 比例 |
|---|---|---|---|
| `nagichat-pc.jpg` | NagiChat · 电脑 | 1920 × 1080 | 16:9 横版 |
| `nagichat-mobile.jpg` | NagiChat · 手机 | 1080 × 720 | 3:2 横版 banner |
| `nagisheart-pc.jpg` | Nagi's Heart · 电脑 | 1920 × 1080 | 16:9 横版 |
| `nagisheart-mobile.jpg` | Nagi's Heart · 手机 | 1080 × 720 | 3:2 横版 banner |

- 电脑版铺满第一屏，标题和按钮叠在图上；手机版是顶栏下方的一条横版 banner，标题、简介和按钮排在图的**下方**，不压图。

- 格式：JPG，文件名必须与上表一致（直接覆盖占位图）。
- 体积：每张尽量不超过 400KB（服务器在新加坡，国内打开大图会慢）。
- 屏幕宽度 ≤ 768px 时显示手机版，其余显示电脑版。

## 二、图上不要放文字

标题（NagiChat／Nagi's Heart）、简介、下载按钮都是网页叠在图上的，**图片本身不要出现任何文字、Logo、按钮或 UI 元素**，否则会和网页上的文字重叠。

## 三、页面会盖住的区域（关键内容避开）

电脑版图片铺满整个屏幕，屏幕比例与图片不同时会裁掉边缘，顶栏和左下角文字会盖在图上；手机版图片完整显示在顶栏和文字之间，不被遮挡。

### 电脑版（1920 × 1080）

```
┌──────────────────────────────────────────────┐
│ 顶栏：左上品牌标志、右上导航（上方约 80px）   │
│                                              │
│‹                   主体放这里              ›│ ← 左右两侧中间各有一个圆形箭头
│               （中间偏右、中上部）             │
│                                              │
│ ┌────────────────────┐                        │
│ │ 标题 + 简介 + 按钮  │  ← 左下角，约宽 700px、   │
│ │（底部渐变变暗）     │     下方约 40% 的高度     │
│ └────────────────────┘        · ━ （圆点）     │
└──────────────────────────────────────────────┘
```

- 顶部约 80px：半透明顶栏（左边品牌、右边导航）。
- 底部约 40%（约 430px）：从下往上逐渐变暗的渐变；左下角放标题、简介和按钮（从左边 50px 起，宽约 600–700px）。
- 左右两侧垂直居中处：各一个直径 48px 的圆形箭头。
- 底部正中：切换圆点。
- 边缘裁切：常见笔记本屏幕（16:10）会裁掉左右各约 100px；超宽屏会裁掉上下各约 140px。
- **构图建议：人物／主体放在画面中间偏右、中上部；左下角保持暗、干净、少细节，方便文字看清。**

### 手机版（1080 × 720）

```
┌──────────────────┐
│ 顶栏（不压图）     │
├──────────────────┤
│                  │
│  banner 图 3:2    │ ← 整张完整显示，不被文字遮挡
│  主体居中          │
│                  │
├──────────────────┤
│ 标题              │
│ 简介（两行）       │ ← 网页文字，在图下方
│ [  按钮  ][ 按钮 ] │
│      · ━         │
└──────────────────┘
```

- 图从顶栏下方开始，完整显示，不裁切，也不被文字、按钮、箭头遮挡（手机上没有箭头，用手指滑动）。
- 在 375px 宽的手机上，图的实际显示大小约为 375 × 250，画面细节不宜太碎，主体要够大。
- 图下方紧接着是深色背景（`#050608`）上的标题和按钮，图的下边缘最好自然过渡到深色。
- **构图建议：主体居中、占画面主要部分；四周各留约 40px 不放关键内容即可。**

## 四、整体风格

与主站现有视觉保持一致：

- 底色偏深：主站背景是近黑的深蓝（`#050608`），图片整体偏暗，和页面自然衔接，不要大面积纯白或高亮。
- 点缀色：电光蓝 `#1a5cff`、青色 `#4fe8ff`（主站按钮和高光都是这个青色）；可以少量用粉紫色（`#b14bff`、`#ff5ea8`）做氛围光。
- 两张之间要有区分，但放在同一个轮播里不能割裂：建议 NagiChat 偏冷的蓝青色调，Nagi's Heart 可以多一点粉紫暖光。

## 五、两张各自的内容

### 第 1 张：NagiChat

- 这是什么：一个聊天 App，里面「住着」凪诚士郎。他有自己的作息、训练和比赛，会累、会偷懒，看到消息会回，也可能晚点回；他记得和你说过的话。
- 想传达的感觉：一个真实在另一座城市过日子的人，日常、松弛、有距离感但心里有你。不是客服式的对话框，也不是甜腻的恋爱海报。
- 画面方向（供参考）：训练结束后坐在更衣室长椅上、低头看手机的凪；或夜里窝在沙发上、屏幕的光照在脸上。安静、生活感，带一点慵懒。

### 第 2 张：Nagi's Heart

- 这是什么：一款乙女向视觉小说（剧情互动游戏），有网页版和 Android 版。
- 想传达的感觉：故事感、心动、有剧情的一幕，比第 1 张更浪漫、更有情绪。
- 画面方向（供参考）：像视觉小说封面或主视觉。凪在某个有故事的场景里（黄昏的球场边、樱花下、雨后的街道），看向画面外的「你」。

## 六、人物参考

凪诚士郎（《蓝色监狱》，Blue Lock），男性：白色／银白色短发，发型蓬松略乱；灰色眼睛；身材高（190cm）；表情常带困意、懒洋洋，偶尔露出认真或温柔的一面。

说明：这是同人致敬站，人物是官方作品的角色。部分 AI 作图工具可能不接受直接生成官方角色，可以改用「白发、慵懒气质的高个少年足球运动员」这类描述做原创风格化的形象。
